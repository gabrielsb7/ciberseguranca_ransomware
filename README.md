🔐 Ransomware Educacional em Python

Projeto desenvolvido para o desafio de Cibersegurança da DIO, utilizando Python no terminal do Kali Linux, com o objetivo de demonstrar conceitos de criptografia e descriptografia de arquivos em um ambiente controlado.

📁 Arquivos

teste.txt — arquivo utilizado nos testes.

encrypter.py — realiza a criptografia do arquivo.

decrypter.py — realiza a descriptografia do arquivo.

⚙️ Funcionamento
teste.txt
   ↓
encrypter.py
   ↓
Arquivo criptografado
   ↓
decrypter.py
   ↓
Arquivo recuperado

🛠️ Tecnologias

Python 3

Kali Linux

Terminal

Criptografia

🎯 Objetivo

Praticar conceitos de cibersegurança, criptografia, programação em Python e utilização do terminal Linux.

⚠️ Aviso

Projeto desenvolvido exclusivamente para fins educacionais, utilizando um arquivo de teste em ambiente controlado. Não deve ser utilizado em arquivos pessoais, sistemas ou computadores de terceiros.
